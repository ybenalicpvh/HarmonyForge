# HarmonyForge

HarmonyForge is a Distributed Real-time orchestrator framework enabling Auto-scaling and Multi-threading capabilities for concurrent task execution.

HarmonyForge is built to be simple and practical, focusing on doing one thing well.

**Why HarmonyForge?**

- HarmonyForge is a Distributed Real-time
- orchestrator framework enabling Auto-scaling and
- Multi-threading capabilities for concurrent task

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/HarmonyForge.git`
2. `cd HarmonyForge`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure HarmonyForge, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
